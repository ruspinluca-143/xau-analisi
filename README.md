# XAU analisi

Analisi dell'oro (XAUUSD) e di azioni USA: time frame da 1 minuto a settimanale, target da 1R a 5R, Time Machine (10.000 simulazioni con barre reali), storico delle casistiche e avvisi nel browser.

**Solo analisi**: nessun broker, nessun ordine. Dati gratuiti e non ufficiali di Yahoo Finance (per l'oro il future GC=F, non lo spot). Non è consulenza finanziaria.

Solo libreria standard di Python: `python server.py` e apri http://127.0.0.1:8765
